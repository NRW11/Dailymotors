# สมุดน้ำมันมอไซค์

เว็บแอป (PWA) จดค่าน้ำมันและเลขไมล์ คำนวณกิโลต่อลิตร สรุปรายเดือน และบันทึกอะไหล่/ถ่ายน้ำมันเครื่อง
ข้อมูลเก็บในเครื่อง (localStorage) ไม่ต้องมีเซิร์ฟเวอร์

## ฟีเจอร์
- บันทึกการเติม: วันที่ เลขไมล์ บาท ลิตร (คิดบาท/ลิตรให้อัตโนมัติ)
- คำนวณ กม./ลิตร ต่อครั้ง และค่าเฉลี่ยรวม (วิธีเติมเต็มถัง)
- อะไหล่ / ถ่ายน้ำมันเครื่อง / อื่นๆ พร้อมแจ้งรอบถ่ายน้ำมันเครื่องถัดไป
- สรุปรายเดือน: ค่าน้ำมัน ค่าอะไหล่ ระยะทาง กม./ลิตร ต้นทุนต่อกิโล
- สำรอง/นำเข้า .json และส่งออก .csv

## วิธีขึ้น GitHub Pages
1. สร้าง repo ใหม่ เช่น `moto-log`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`) ไว้ที่ root
3. Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
4. เปิด `https://<username>.github.io/moto-log/` บนมือถือ แล้วเลือก "เพิ่มลงหน้าจอโฮม"

## หมายเหตุ
- ข้อมูลอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่ซิงก์ข้ามเครื่อง ใช้ปุ่มสำรองข้อมูลในหน้าตั้งค่าเป็นระยะ
- ถ้าแก้โค้ดแล้วหน้าเว็บไม่อัปเดต ให้เปลี่ยนเลขเวอร์ชัน `CACHE` ใน `sw.js`
